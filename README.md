# hc-ui

我做中文学术写作与学生日常里的零依赖小工具——Word 文档和国家标准之间缺失的那些管道。

Small, zero-dependency tools for Chinese academic writing and student workflows.

| 项目 | 干什么 |
|---|---|
| [gbt7714-lint](https://github.com/hc-ui/gbt7714-lint) | GB/T 7714—2025 新国标参考文献格式检查与自动修复 · [在线试用](https://hc-ui.github.io/gbt7714-lint/) |
| [zh-cite-check](https://github.com/hc-ui/zh-cite-check) | 正文引用序号与参考文献表一一对应检查 |
| [docx-reply](https://github.com/hc-ui/docx-reply) | Word 批注与修订一键导出成修改对照表 |
| [luanma](https://github.com/hc-ui/luanma) | 解压乱码文件名自动检测与修复（GBK / Big5 / Shift-JIS / EUC-KR） |
| [kebiao2ics](https://github.com/hc-ui/kebiao2ics) | 大学课表转手机日历 .ics · [在线使用](https://hc-ui.github.io/kebiao2ics/) |

Plain-text first · offline friendly · MIT licensed. Issues & PRs welcome，中英文皆可。
